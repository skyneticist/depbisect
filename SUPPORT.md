# Getting help

Thanks for using DepBisect! Here is where to go for each kind of question.

- **Start with the docs.** The [README](README.md) covers install and usage;
  [docs/how-it-works.md](docs/how-it-works.md) explains the pipeline, and
  [docs/limitations.md](docs/limitations.md) covers unsupported cases and how to
  read each exit code.
- **A bug or unexpected result?** Open a
  [bug report](https://github.com/skyneticist/depbisect/issues/new?template=bug_report.md).
  Attaching `depbisect-report.json` helps a lot — it contains no environment
  values or captured command output.
- **An idea or feature request?** Open a
  [feature request](https://github.com/skyneticist/depbisect/issues/new?template=feature_request.md).
- **A security issue?** Please do not file a public issue — follow
  [SECURITY.md](SECURITY.md) instead.

This is a small project maintained on a best-effort basis, so please be patient
with response times. Before opening an issue, a quick search of
[existing issues](https://github.com/skyneticist/depbisect/issues) may already
have your answer.
